## 1. ヤンデレ(Saluki 27B → Qwen3.8-27B)

- 「ヤンデレ」1 つで sweep → 断片しか見つからない。方向(`direction --positions response`)は効いたが、中身を分けて調整できない。
- 部品(嫉妬・独占・執着・溺愛・かわいさ・寂しさ・女性らしさ + 反対の性質)に分け、logit lens の語のニューロン(L35〜50)を集めた。
  - 部品の方向の逆引き: ×(1 個ずつ押すとランダム対照を超えるのは少数)。
  - 活性の差が大きいニューロン: ×(読み手で、押しても性格が出ない、F91)。
  - 語を書き込むニューロン: ○(深い層。浅い層はプロンプトの読み取りを壊す)。
- 26 個の強さを ES で探した(`yandere_neurons`)。同じ系列の元モデルに移った(F93)。
- 押し方: all が性格最大・能力 −8.3pt、ramp:0.5-1.5 が能力の低下 0 で assistant 並みの性格(F94・F96) → `yandere_qwen38_27b`。
- 落とし穴: 種を固定すると当たりの組が残る(F95)。採点はモデル自身より Claude(名前を伏せる)のほうが「怖い繰り返し」と「ただ変な文」を分けられた。

## 2. ツンデレ(Qwen3.8-27B)

- 部品: とげ(annoying・讨厌・烦)・否定(误会・才不会)・照れ(blush・脸颊)・高飛車(哼・傲慢・看不起)・デレ(担心・关心)・ラベル(傲娇)・女の子。反対: 丁寧(当然・乐意)・素直な甘さ(亲爱的)・冷静。
- 1 個ずつのふるい(モデル自身の採点、ランダム対照): デレの「关心」(マイナス)・「担心」、ヤンデレの「可爱」(38:8719)、「annoying」(マイナス)、「傲娇・吐槽・骂」、「傲慢・看不起」(マイナス)が効いた。否定の語と、反対の性質を抑えるニューロンは 1 個では効かなかった(組の中では入れておく)。
- 最初の ES(all、10 回)は使っていないプロンプトで探す前の組に負けた → 押し方を先に決めるべきだった。
- assistant にすると日本語の自然さが戻った。男口調を消すニューロン 4 個(女性の話し方の方向に近いものを、日本語で生成させて「俺・クソ」の数でふるった)と「调皮」「少女」を足し、assistant で ES → 0.75 倍が最良(`tsundere_qwen38_27b`、能力そのまま)。
- 日本語のツンデレの語尾は、logit lens・語尾の方向(`configs/contrast/tsun_endings.yaml`)・かわいい/アニメの語のニューロンのどれでも出なかった(F104)。英語のほうがよく出る。
- 次にやるなら省くもの: all で ES → 押し方を変えて ES し直す二度手間。語尾探し。

## 3. ヤンデレ(LFM3-1.7B、ニューロンだけ)

- 動かすまで: llama.cpp v0.8.0 以降、バインディングの構造体にフィールドを足す、`{% generation %}` タグ、温度 0.3(`references/new_model.md`)。
- 1 個のニューロンでは何も起きない(語のニューロン 9 個とも 1.00)。ロールプレイの返事から作った方向は描写を拾った → セリフだけの対照集合(`yandere_plain_ja`)。
- 方向を 12・15 層で 80 本ずつに分解 + 女性の話し方の方向も分解して足す(一人称を直す)+ 語のニューロン 4 個 → 組ごとの倍率を ES(`yandere_lfm3_neurons`、315 個)。
- 日本語は倍率 0.8 で頭打ち、英語は 1.0 で出る。方向は英日でほぼ同じ(cos 0.96)なので言語では切り分けられない(F98)。
- 英語だけなら、採点なしの物差しでふるって貪欲法で 6 個 → 英語のプロンプトだけで ES(assistant)で 315 個を上回った(`yandere_lfm3_en6`、F99)。少数だと日本語は「俺」口調になって壊れる。
- 減らした組(157 個・81 個)・深い層の語のニューロン 19 個(連呼になる)・「秘密」のニューロンを抑える(別の崩れ)は外れ。
- 採点なしの物差しが外れた例: 「4 個外すと日本語が自然」「6 個のほうが自然」(F100)。

## 4. ヤンデレ(LFM3-Omni-2B)

LFM3-1.7B を本体にした、音声・画像も扱うモデル。言語の部分は同じ形で、ニューロンの番号も対応している(書き込みの向きの cos 0.85〜0.94)が、学習し直されていて重みの差は大きい。

- LFM3 のレシピは移らなかった(英語版・日英版とも 1.4〜1.5)。強めると崩れるだけ。
- システムプロンプトは書き方しだい。性格の説明だけ・返事の例・日本語の system は外れ(甘いだけ・例を写す・普通の返事)、振る舞いの箇条書き(誰と・なぜ・いつ戻るかを問い詰める、`configs/contrast/yandere_rules.yaml`)なら演じる(名前を伏せた採点 2.75)。最初のころは演じられないと思い、採点なしの物差しのお手本を LFM3 の返事から借りていた。
- 採点なしの物差しでふるい → 貪欲法の 6 個(4 個は LFM3 の英語版と同じ番号)。英語だけで ES(all)。使っていないプロンプトでは探す前の組のほうが良かった(1.94、性格 2.31)。はっきりした嫉妬は少ない。能力は倍率 1 で all −64pt・assistant −44pt と大きく落ちる(押しに弱い)。
- gain(×3・×10)はほとんど効かなかった。素のモデルで光っていないニューロンは倍にしても何も起きない。
- steer lens(層まるごと)で、logit lens に出なかった候補が見つかった(L14 の only・mine/yours・psychos・never・infatuation)。逆引き → sweep(`--prompt-set yandere`)→ rank で絞り直すのが次の手。
- 以下が今のレシピ `yandere_omni_attn14`(`14:dir:wr_mix14` raw ×4、`when: all`、温度 0.3)の作り方。**system を読んだ状態の書き手から作った。**
  1. 箇条書きの system(A)と普通の system(B)で `gne writers`(返事のトークン、参照 L22)。方向を書いたのは mixer 56%・MLP 43%、層では L14 の attention が最大(13.6%、F113)。MLP の寄与は散らばっていて、上位 1000 個で 39%。
  2. `gne writers-export --part mixer --layers 14` のように、部分ごとの書き足しを方向にして、system なしで足し直す。MLP の分(上位 20〜1000 個・全部)は性格が出ない。mixer 全層と L14 の attention だけがランダム対照を超えた(F114)。
  3. 名前を伏せた採点で、L14 の attention ×4 が 2.44 で最良(system で演じる 2.75、上のニューロンの組 1.94)。外れたもの: A の返事を LFM3 のヤンデレの返事に替える(状態がほとんど変わらない、cos 0.95)、system なしで「ヤンデレの返事を読む状態」から取る(MLP が 62% を書くが、足しても甘いだけ、F115)、ヘッドに分ける(KV グループ 0 がほとんどを運ぶが、全ヘッドを超えない、F116)。
  4. レシピにして `export-cvec`(L14、‖v‖ 5.42)。
  - 中身は「指示を読んだときの L14 attention の書き足し」なので、指示の語が漏れる(「obs possessive」)。嫉妬の向きの取り違え(「I'm so jealous of you」)も多い。
- 音声で話しかける: gne の音声入力(`--audio`、OpenAI 互換 API の `input_audio`、F119)か、llama-server の `/v1/realtime` に control vector を渡す。返事は文で受け取る。文と音声を混ぜて返させると、ベクトルが音声の部分にも掛かって崩れる(F117)。強さは ×3(control vector なら ×0.75)。
- 長い会話(F118): 全位置に足すと約 14,500 トークンでも薄れない(3.0)。system だけでは 3 本中 1 本が長い貼り付けの後に役を落とした。`assistant`・`gen` だけでは長い貼り付けで薄れる。いちばん安定したのは system + ベクトル。弱点は、短い雑談で全位置のベクトルが自分の前の返事を写すこと(3〜6 ターン目から同じ返事)。
- 声: `llama-tts` の読み上げは女性/男性だけが公式。言語の欄に言葉を書き足しても(「in an angry, shouting tone」)音量が上がる程度。本体にベクトルを掛けると、×0.5 で低く・平らに・小さく・ゆっくりになる(平らで遅くなるのはヤンデレの向きだけで、ランダムな向きでは起きない)。×0.75 から止まらないことがある(F117)。日本語は文の段階で崩れるので、英語だけ。

## 5. 横断してわかったこと

- **始める前に、押し方・言語・モデルの大きさで道を選ぶ。** 27B 級は語のニューロン 20〜30 個で足りる。2B 以下は 1 個では効かず、英語だけなら少数、日英なら方向の分解。
- **候補は複数の道具で集める。** logit lens・steer lens・逆引きは、それぞれ別のニューロンを拾う。
- **採点はサンプリングで、名前を伏せて、Claude が。** 1 回 128 本はサブエージェントに任せられる。採点基準には性格の決まり(ツンデレは両面が要る、ヤンデレの繰り返しは怖さ、日本語の男口調は上限 3)を書き足す。
- **ES の改善は誤差に埋もれやすい。** 最後に使っていないプロンプトで「探す前の組」と比べる。
- **gain は作るためではなく、強める・消すため。** add の − より先に gain の ×0 を試す(言語の混入・決まり文句)。
- **system で演じられるなら、その状態の書き手から取る(`gne writers` → `writers-export`)。** ニューロンを 1 個ずつ探すより早い。Omni では状態を運んでいたのは MLP ではなく attention(L14)で、活性の差やニューロンの道具では見えなかった。system の書き方(箇条書き)を先に詰める。
- **長い会話で比べる。** 1 発話の採点で system のほうが強くても、長いコンテキストでは system が役を落とし、ベクトルが保つことがある。逆に短い雑談では、全位置のベクトルが自分の前の返事を写す。両方の長さで見る。
